# SillyTavern Timelines 扩展 (Pro / Luker Refactor)

> 💡 **项目完整 Wiki 文档与架构开发指南**：详见 [WIKI.md](./WIKI.md)。

![STTL_screenshot](https://github.com/Technologicat/SillyTavern-Timelines/assets/16972251/7fccb43f-b4f6-4e1d-8fdf-3bd68dfb1969)

Timelines 是一个用于按多维时间树导航 SillyTavern/Luker 聊天历史的现代化前端插件。构建于原生聊天数据契约之上，致力于为大语言模型（LLM）角色扮演和分支叙事提供全景探索、差异对比、剧情大纲梳理与数据量化工作台。

## 🌟 核心功能矩阵 (Feature Matrix)

- ⚡ **全链路高性能拓扑引擎**：二级增量 JSONL 文件缓存 (`timelinesCache`)，Web Worker 异步 Dagre 布局，千节点毫秒级 O(1) 祖先回溯。
- 🗺️ **全景小地图与鸟瞰穿梭**：顶部折叠式双缓冲 Canvas 小地图，带视口取景框几何投影与拖拽居中平移。
- 🌿 **节点右键分支管理**：严格遵循原生契约，支持在任意节点一键创建新分支与安全删除分支。
- ⚖️ **分支深度 Diff 对比**：智能计算最近公共祖先节点 (LCA)，双栏毛玻璃对比分流前后剧情演化轨迹。
- 🍒 **单消息 Cherry-Pick 采摘与合并**：将任意分支的关键消息一键采摘至当前会话，或基于分叉点派生新分支进行剧情合并。
- 🏷️ **原生彩色标签与书签系统**：非破坏性持久化于 `message.extra`，提供分类索引抽屉与视口聚焦脉冲。
- 📖 **全局故事大纲视图**：主干因果链自动提取，智能分章聚合，提供剧情卡片流与 Markdown 研报导出。
- 📊 **剧情分支量化分析看板**：统计总节点、结局分支、最大深度、角色发言天平比例柱状图、Swipes 探索率与高频标签排行。
- ⏳ **分支检查点与时光机画廊**：全时间树书签与关键分流点纵向画廊，支持实时模糊搜索、一键视口定位与跨分支时空穿越。
- 🔍 **智能全景雷达与多维检索**：支持正则表达式语法 (`/pattern/flags`)、角色切片、书签/标签筛选、楼层切片、结果步进器与全图半透明调光。
- 🧠 **语义跨会话检索（可选 Authority 集成）**：向量 + BM25 混合语义检索，内容指纹增量索引，未打开分支会话命中可跨会话弹窗直达楼层；支持跨角色全局检索（按来源分组）、书签/标签复合筛选与相邻楼层上下文芯片，数据看板聚合全库索引状态；未安装 Authority 时零依赖零行为变化。
- 🪶 **渐进式渲染与细腰图内存极压**：画布先行、单文件粒度增量上屏与全程进度胶囊；弱设备自动截断节点预览、按需就地展开全文，千节点级大图不再卡顿爆内存。
- 📷 **超大画幅高保真导出**：支持 4K/8K 印刷级长图海报与完全无依赖的独立 SVG 矢量图导出，内置安全防爆缩放保护。
- 📱 **移动端全景优化**：禁用框选冲突，优化捏合手势防抖，触屏长按呼出菜单，界面全面响应式自适应。
- 🔌 **微内核解耦开放 API**：`window.TimelinesExtensionApi` 支持第三方插件通过节点装饰器注水（如记忆图谱 Memory Graph 零耦合适配）。

## 安装与使用

### 安装

使用 ST/Luker 内置扩展安装器安装本插件。

### 使用

- 设置入口：`扩展 > Timelines`
- 打开时间线视图：`扩展 > Timelines > 显示时间线`
- 斜杠命令：
  - `/tl`：打开时间线视图，等同于点击“显示时间线”按钮。
  - `/tl r`：重新加载时间线图。

如需一键访问，可把 `/tl` 绑定到自定义 Quick Reply 按钮。短标签可以使用“⏳”（U+23F3，沙漏符号）。

## 图中元素

- 带有 swipes 的节点会显示光环，也可以在设置中让这类节点略微变大。
- 检查点节点会显示彩色外环。使用界面主题时，外环为金黄色；使用自定义主题时，颜色可配置。
- 检查点路径会按对应颜色高亮，并显示在图例中。检查点颜色是随机色，但由检查点名称稳定决定。
- 只有当源聊天文件中仍存在有效检查点链接时，检查点路径才会被识别；失效链接会被忽略。
- 内容自动合并只合并同一聊天深度的相同消息，因此图始终是有向无环图。

## 交互

- 打开时间线视图时，会自动缩放到当前聊天，并闪烁该聊天中的最后一个节点。
- 悬停节点会显示消息预览，并高亮所有相连边。
- 长按带有 swipes 的节点会在图上显示或隐藏对应 swipe 节点。
- 点击节点会打开完整信息面板，可跳转到包含该消息的聊天，或从该消息创建新分支；省内存模式下被截断的节点可在面板中一键「展开全文」或「复制全文」，右键菜单也提供「复制消息全文」。
- 双击节点会快速打开第一个匹配聊天；如果同一消息出现在多个聊天文件中，会显示自动选择的文件名。
- 点击边会跳转到离点击位置更远的端点并缩放到该节点。
- 点击图例项会高亮并缩放到对应节点或路径，再次点击同一项会取消高亮。
- 搜索框使用增量片段搜索：查询会按空白拆成多个片段，所有片段都匹配时才算命中，片段顺序不重要。

## 检查点说明

检查点是一个带名称的聊天分支。分支和检查点本质上都是独立聊天文件；旧术语“书签”在这里等同于“检查点”。

Timelines 自身只创建未命名分支。检查点需要在 ST/Luker 主界面中创建：找到目标消息，打开该消息的“消息操作”，点击“检查点”。如果启用了“展开消息操作”，该按钮会直接显示；否则通常位于“...”菜单中。

删除分支或检查点时，可使用 ST/Luker 内置的聊天文件管理视图，或在文件管理器中删除对应聊天文件。

检查点追踪有一个细节：创建检查点会生成新的检查点聊天文件，也会在源聊天文件的对应消息中插入检查点链接。Timelines 会沿着这些链接追踪检查点路径，并忽略指向不存在文件的失效链接。

## 前置条件

SillyTavern 版本不低于 1.10.4。Luker 环境按其前端插件兼容层加载。
