# SillyTavern Timelines 扩展

![STTL_screenshot](https://github.com/Technologicat/SillyTavern-Timelines/assets/16972251/7fccb43f-b4f6-4e1d-8fdf-3bd68dfb1969)

Timelines 是一个用于按时间线导航 SillyTavern/Luker 聊天历史的前端插件。它的思路类似 *Loom* [[1]](https://generative.ink/posts/loom-interface-to-the-multiverse/) [[2]](https://www.lesswrong.com/posts/bxt7uCiHam4QXrQAA/cyborgism#Appendix__Testimony_of_a_Cyborg)，但建立在 ST/Luker 的聊天范式之上。

## 功能

- 显示当前角色的所有聊天。同一深度中内容相同的消息会合并为一个时间线节点。
- 对当前角色的全部消息内容做实时全文过滤。
- 支持基于界面主题或自定义颜色的图样式。
- 可从任意聊天消息或 swipe 创建新分支。
- 支持检查点路径高亮、图例、节点悬浮预览、完整信息面板和快捷跳转。

## 安装与使用

### 安装

使用 ST/Luker 内置扩展安装器安装本插件。

### 使用

- 设置入口：`扩展 > Timelines`
- 打开时间线视图：`扩展 > Timelines > 显示时间线`
- 斜杠命令：
  - `/tl`：打开时间线视图，等同于点击“显示时间线”按钮。
  - `/tl r`：重新加载时间线图。

如需一键访问，可把 `/tl` 绑定到自定义 Quick Reply 按钮。短标签可以使用“⏳”（U+23F3，沙漏符号）。

## 图中元素

- 带有 swipes 的节点会显示光环，也可以在设置中让这类节点略微变大。
- 检查点节点会显示彩色外环。使用界面主题时，外环为金黄色；使用自定义主题时，颜色可配置。
- 检查点路径会按对应颜色高亮，并显示在图例中。检查点颜色是随机色，但由检查点名称稳定决定。
- 只有当源聊天文件中仍存在有效检查点链接时，检查点路径才会被识别；失效链接会被忽略。
- 内容自动合并只合并同一聊天深度的相同消息，因此图始终是有向无环图。

## 交互

- 打开时间线视图时，会自动缩放到当前聊天，并闪烁该聊天中的最后一个节点。
- 悬停节点会显示消息预览，并高亮所有相连边。
- 长按带有 swipes 的节点会在图上显示或隐藏对应 swipe 节点。
- 点击节点会打开完整信息面板，可跳转到包含该消息的聊天，或从该消息创建新分支。
- 双击节点会快速打开第一个匹配聊天；如果同一消息出现在多个聊天文件中，会显示自动选择的文件名。
- 点击边会跳转到离点击位置更远的端点并缩放到该节点。
- 点击图例项会高亮并缩放到对应节点或路径，再次点击同一项会取消高亮。
- 搜索框使用增量片段搜索：查询会按空白拆成多个片段，所有片段都匹配时才算命中，片段顺序不重要。

## 检查点说明

检查点是一个带名称的聊天分支。分支和检查点本质上都是独立聊天文件；旧术语“书签”在这里等同于“检查点”。

Timelines 自身只创建未命名分支。检查点需要在 ST/Luker 主界面中创建：找到目标消息，打开该消息的“消息操作”，点击“检查点”。如果启用了“展开消息操作”，该按钮会直接显示；否则通常位于“...”菜单中。

删除分支或检查点时，可使用 ST/Luker 内置的聊天文件管理视图，或在文件管理器中删除对应聊天文件。

检查点追踪有一个细节：创建检查点会生成新的检查点聊天文件，也会在源聊天文件的对应消息中插入检查点链接。Timelines 会沿着这些链接追踪检查点路径，并忽略指向不存在文件的失效链接。

## 前置条件

SillyTavern 版本不低于 1.10.4。Luker 环境按其前端插件兼容层加载。
