# PRD: 超大画幅高保真导出与长图分享系统 (High-Res Canvas / SVG Export & Sharing)

## 1. 背景与目标 (Background & Objective)
用户在酒馆/Luker 中推进长剧情时，分叉树逐渐庞大而精美，包含了大量关键检查点、分支抉择、彩色标签与人物记忆。目前仅能在模态框内部缩放平移查看，缺乏一键导出为超清全景长图、分享到社交平台或本地持久化归档的能力。

本任务旨在为 Timelines 构建一套开箱即用的高保真导出与分享引擎：
1. 支持高分辨率位图（PNG 1x / 2x / 4x 超采样）与无损矢量图（SVG）全景导出；
2. 提供典雅的导出配置对话框，支持自定义背景、水印标题卡片（包含角色名、总节点数、因果分支数、生成时间戳）；
3. 支持一键下载文件与直接复制到系统剪贴板（Clipboard API）；
4. 顶部工具栏与右键菜单提供便捷入口，全过程对主图画布零破坏。

---

## 2. 核心用户故事 (User Stories)
- **US-1**: 作为酒馆剧情创作者，我想将当前完整的时间线分叉树一键导出为超清 PNG 长图，方便在 Discord / QQ 频道或论坛向其他玩家分享剧情分支走向。
- **US-2**: 作为归档爱好者，我想导出无损矢量的 SVG 图表，即便包含数百条消息节点也能无限放大查看每个细节。
- **US-3**: 作为移动端/桌面端用户，我想在导出图底部带有自动生成的雅致“剧情分支长卷”水印卡片，记录会话名、角色头像和导出时间。
- **US-4**: 我想快速将时间线截图复制到系统剪贴板，无需经历“下载文件-打开文件夹-粘贴”繁琐步骤。

---

## 3. 功能需求与验收标准 (Acceptance Criteria)

### AC-1: 格式与清晰度
- 支持 PNG（标清 1x、高清 2x Retina、超清 4x 印刷级）与 SVG 矢量图；
- 导出包含完整的 Cytoscape 图形元素、连线样式、角色头像、书签标识与彩色标签徽章；
- 针对超大图谱设置最大尺寸安全上限（8192px），防止浏览器 Canvas 发生 OOM 崩溃。

### AC-2: 导出弹窗 (`ExportModal`)
- 点击顶栏 `.export-timeline-btn`（`fa-solid fa-camera`）唤出导出配置浮层；
- 用户可勾选：
  - 导出范围：全图 (Full Canvas) / 视口所见 (Current Viewport)；
  - 水印卡片：是否在图谱下方嵌入精致的剧本元数据信息栏（角色名、时间、节点计数）；
  - 背景色：暗色透明 / 纯黑 (#0d1117) / 主题色；
- 操作按钮：`⬇️ 下载图像文件`、`📋 复制到剪贴板`、`❌ 取消`。

### AC-3: 原生与安全性契约
- 零第三方私有依赖，纯前端 Canvas / SVG Blob 生成；
- 导出时临时计算并保持用户当前时间线画布的缩放、平移状态不变，杜绝 UI 闪烁或状态丢失；
- 在剪贴板 API 受限（如非 HTTPS 跨域上下文）时优雅降级并引导直接下载。
