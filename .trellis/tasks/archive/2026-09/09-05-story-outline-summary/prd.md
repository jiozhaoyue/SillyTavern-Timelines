# PRD: 时间线全局故事大纲视图与关键剧情摘要卡片流导出 (Story Outline & Summary)

## 1. 背景与用户痛点
在使用 SillyTavern 进行深度跑团和长篇角色互动时，随着剧情的发展，分叉树动辄包含数十至上百个节点。
玩家在复盘长篇故事或向朋友分享时，常常面临两大难题：
1. **见树不见林**：节点图非常直观展示因果分叉，但缺少**线性叙事与章节大纲视角**，难以一览故事的“序幕、起承转合、分支走向与重要事件”；
2. **缺乏文档化提炼导出**：无法快速一键生成结构清晰的 Markdown 故事大纲或剧情摘要长文档，用于笔记软件（如 Obsidian/Notion）归档或社区发布。

## 2. 核心目标
1. **全局故事大纲自动提炼算法 (`src/story-outline-service.js`)**：
   - 基于分叉点（Branch Points）、原生彩色标签（Tags）、书签（Bookmarks）与发言轮次跨度，自动将多分支图谱结构化切分为“剧情章节/幕 (Chapters)”；
   - 提取各章节核心对话与行动摘要（支持中英文长文本截断与重点保留）；
   - 计算故事宏观统计（总字数、关键分歧点、多分支走向梳理）。
2. **交互式故事大纲抽屉/模态框 (`src/story-outline-modal.js`)**：
   - 顶栏增加 `.toggle-story-outline` 按钮（`fa-solid fa-book-open`，标题“故事大纲与剧情摘要”）；
   - 点击唤出结构清晰的大纲卡片流；
   - 点击任意大纲事件卡片，时间线画布自动平滑聚焦并脉冲高亮（`tl-node-pulse`）对应节点。
3. **多格式高保真导出**：
   - **Markdown 大纲文档**：包含多级标题、时间轴列表、关键引用台词与标签徽章，支持一键复制到剪贴板与下载 `.md` 文件；
   - 支持直接以卡片流形式浏览，或一键调取现有的高保真长图导出。

## 3. 验收标准
- [ ] 编写纯单元测试 `tests/story-outline.test.mjs`，验证大纲分章算法、摘要提取与 Markdown 渲染无误；
- [ ] 在 Luker 实机环境打开大纲面板，章节与事件卡片渲染完整；
- [ ] 点击卡片联动画布聚焦并闪烁对应节点；
- [ ] 测试一键复制 Markdown 大纲与下载 `.md` 文件成功；
- [ ] 截图留存并归档 Trellis 任务。
