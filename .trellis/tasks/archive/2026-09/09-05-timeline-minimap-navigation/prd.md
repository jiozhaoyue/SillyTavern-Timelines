# PRD: 时间树全景小地图与鸟瞰拖拽导航 (Timeline Minimap & Bird-Eye Navigation)

## 1. 背景与目标

在多分支长篇角色扮演对话中，分支拓扑图规模往往达到数百至数千个节点，横跨数十层。用户放大局部阅读具体台词时，容易迷失在巨型图谱中，难以快速感知全局拓扑位置。

本任务旨在为 Timelines 提供一个**极致轻量、丝滑同步、支持拖拽**的全景小地图 (Minimap)：

1. **全局鸟瞰概览**：在视口角落提供一个半透明、可折叠的 2D Canvas 小地图，实时缩略呈现整棵对话树的拓扑分布与分支走向。
2. **视口取景框指示**：小地图上绘制半透明高亮矩形框，实时同步主画布当前可见视口区域（主画布缩放/平移，取景框同步变换）。
3. **点击/拖拽快速定位**：
   - 在小地图任意位置单击，主视口立刻平滑飞至目标节点群。
   - 拖拽小地图中的取景框，主画布视口实时跟随平移。
4. **性能零损耗**：采用原生 Canvas 2D 轻量投影与 rAF 帧率节流，即使 1000+ 节点绘制耗时也控制在 < 1ms 内，绝不增加主图渲染负担。

---

## 2. 功能需求详情

### 2.1 小地图容器与 UI 规范

- 挂载在 `#networkContainer` 内（建议左下角或左侧），避免遮挡右侧图例与顶部控制栏。
- 采用磨砂玻璃暗色风格，圆角 8px，带有精细边框与投影。
- 右上角提供折叠/展开微型按钮（图标：`fa-map` / `fa-compress`）。折叠后仅保留一个小图标，点击即展开。

### 2.2 视口映射与双向同步机制

- **坐标投影算法**：计算全图的外接包围盒 $BoundingBox = \{x_1, y_1, x_2, y_2\}$，将全图等比缩放投影至 Canvas 视口。
- **节点绘制**：按角色/用户颜色将节点投影为微型粒子点（半径 1.5px~2.5px），分支连线以极细半透明线段勾勒。
- **当前视口框 (Viewport Indicator)**：计算主图 `cy.extent()`，将其逆投影为小地图上的矩形线框与半透明填充层。
- **事件联动**：
  - 监听 Cytoscape 的 `pan`、`zoom`、`position` 事件，通过 `requestAnimationFrame` 节流更新取景框。
  - 监听 Canvas 的 `mousedown` / `touchstart` 与 `mousemove` / `touchmove`：
    - 点击取景框外部：将主图居中至点击对应的全图逻辑坐标。
    - 按住取景框内部拖拽：主图视口以同等比例实时平移。

---

## 3. 验收标准

1. 打开时间线后，小地图正确渲染全局节点分布与视口取景框。
2. 主画布平移或缩放时，小地图取景框无延迟、无卡顿同步移动与缩放。
3. 点击或拖拽小地图取景框，能精准将主画布定位至目标区域。
4. 提供折叠与展开功能，移动端或桌面端均不遮挡核心内容。
5. 单元测试覆盖坐标投影与取景框映射纯数学逻辑；实机与 CDP 测试验证通过。
