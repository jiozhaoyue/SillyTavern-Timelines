# PRD: 时间线分支高级管理与差异对比 (Branch Management & Diff View)

## 1. 背景与目标
在多分支角色扮演对话中，用户经常在关键剧情转折点产生不同分支。当前 Timelines 插件仅支持双击跳转到已存在的分支消息，缺乏直接在图谱上对分支进行生命周期管理（直接派生新分支、删除孤立分支）以及横向对比多分支剧情走向（Diff View）的能力。

本任务旨在：
1. **启用并深度定制右键上下文菜单**：通过 `cytoscape-context-menus` 提供右键交互入口。
2. **支持节点级快速分叉与克隆 (Branch From Node)**：右键任意节点一键从该处生成新聊天记录分支并切换。
3. **多分支差异对比 (Branch Diff View)**：支持选择两个分支端点（或右键指定对比目标），以最近公共祖先 (LCA) 为基准，提供直观的双栏剧情走向与消息差异对比。
4. **安全分支清理 (Delete Branch)**：支持在叶子节点处安全删除废弃的会话分支，并带防手滑确认与时间线实时刷新。

---

## 2. 功能需求详情

### 2.1 节点右键上下文菜单 (Node Context Menu)
- 右键非根消息节点 (`node[?msg]`) 弹出菜单：
  1. `🔀 从此处创建新分支 (Branch from here)`: 自动调用 `createBranch(messageId)`，创建并跳转到新分支。
  2. `🔍 跳转到此消息 (Navigate to message)`: 切换到对应会话并滚动至该楼层。
  3. `⚖️ 与当前分支对比 (Diff with current branch)`: 以此节点所在分支与当前活跃分支进行差异对比。
  4. `📌 标记为对比基准 A (Set as Diff Base A)`: 供跨分支自由选择任意两个端点进行对比。
  5. `🗑️ 删除此会话分支 (Delete chat branch)`: 仅在叶子节点（或会话末尾节点）提供，确认后调用后端 API 删除文件。
- 样式适配：使用酒馆 CSS 变量，支持半透明磨砂背景、高对比度文字与悬浮动效。

### 2.2 多分支差异对比弹窗 (Branch Diff Modal)
- **LCA 拓扑算法**：计算两个分支从根节点到各自末端的全路径，找出最后一个相同消息节点（最近公共祖先分叉点）。
- **差异呈现**：
  - 分叉前：显示分叉点摘要（发言人、文本截断、楼层）。
  - 分叉后：左右并列双栏对比：
    - 左栏：分支 A 的后续发展（轮次、角色、文本、Swipe 版本）。
    - 右栏：分支 B 的后续发展（轮次、角色、文本、Swipe 版本）。
  - 提供快捷切换按钮，可在对比面板中一键“切换到此分支继续对话”。

### 2.3 性能与状态协同
- 分支创建与删除必须自动触发 `TimelinesCache` 对应作用域缓存更新与时间线图重绘。
- 在 Diff 比较超长分支（如各自发展了 100+ 轮）时，Diff 弹窗采用虚拟滚动或按需折叠，保障渲染丝滑。

---

## 3. 验收标准 (Acceptance Criteria)
1. 在时间线画布上右键节点，能精准弹出美观的上下文菜单。
2. 点击“从此处创建新分支”能在酒馆中派生出新会话文件，并自动刷新图谱显示新分支节点。
3. 对任意两个分支触发“分支差异对比”，能准确计算 LCA 分叉点并在模态框内清晰展示两侧消息差异。
4. 删除分支有确认弹窗，删除成功后图谱中该分支节点立即移除。
5. 所有单元测试通过，全流程不阻塞主线程。
